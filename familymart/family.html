FamilyMart App
UX Redesign

優化便利商店高頻使用情境，提升操作效率

Project Type UX/UI Design Project
Tools Figma / Prototyping
Team / Role Solo Project
UX Research / UI Design

Project Overview

本專案針對全家便利商店 App 進行 UI/UX 改版， 聚焦於「高頻使用情境」，優化資訊架構與操作流程， 提升使用效率與決策速度。

User Flow

本設計聚焦兩大核心流程：快速兌換商品與快速轉贈商品， 讓使用者在最少步驟內完成任務。

Key Features

核心功能與使用者價值

高頻功能前置（條碼 / 支付 / 兌換）
→
降低操作步驟，提升結帳效率
「你現在最需要」任務導向
→
使用者可快速知道當下要做什麼
門市庫存 + 偏好門市提示
→
一眼判斷哪裡可以兌換
一鍵轉贈 + 常用對象
→
降低送禮流程成本

Persona

針對不同使用情境，建立兩種典型使用者輪廓

林子翔
28歲｜上班族

上班途中或午休，用最少時間完成購買，之後再找方便的門市兌換

目標

  • 用最短時間完成購買與兌換
  • 清楚掌握可使用商品

動機

  • 時間零碎，不想研究介面
  • 希望流程穩定、不出錯

痛點

  • 功能分散，要先思考去哪
  • 不清楚門市庫存，怕白跑
陳怡安
24歲｜學生

臨時需要送禮，用最快方式把商品轉贈給對方

目標

  • 快速完成送禮
  • 確保對方能順利兌換

動機

  • 情境突然發生
  • 希望送禮流程自然不尷尬

痛點

  • 流程繁瑣需多次確認
  • 每次都要重新找對象

Design Opportunity

如何讓使用者在「趕時間」的情境下， 能快速完成購買、兌換與轉贈， 並降低資訊搜尋與決策成本？

User Research

透過 App Store 評價分析，整理出三大使用痛點： 功能層級混亂、決策負擔過高、門市資訊不直覺， 作為本次 UI/UX 改版依據。
