Project Type Web Design
Tools HTML / CSS / JavaScript
Team / Role 4 People Team
UI / Interaction / Dev

Project Overview

「修起來」是一款以「簡單、直覺、即時互動」為核心的線上圖片編輯網站。 使用者可直接在瀏覽器中上傳圖片，透過濾鏡、貼紙、調色、塗鴉筆與拼圖模板等功能， 快速完成個人化影像創作。 本專案著重於降低圖片編輯門檻，讓沒有專業背景的使用者， 也能透過拖曳與點擊輕鬆完成設計，並支援多裝置使用， 打造兼具趣味性與實用性的互動體驗。

Design Concept

本網站以「人人都能輕鬆創作」為核心概念， 強調直覺式操作與即時回饋。 透過滑鼠拖曳、點擊與視覺化介面設計， 讓使用者在無需學習成本的情況下完成圖片編輯。 同時結合動態效果與互動回饋， 提升整體操作的流暢感與趣味性， 讓編輯圖片不只是工具，而是一種創作體驗。

本網站包含首頁、圖片編輯、拼圖功能與展示牆等主要模組， 整合多種圖片處理功能，並透過清楚的流程設計， 讓使用者能快速完成從上傳、編輯到分享的完整體驗。

Home Page

首頁作為整體網站的入口，整合圖片上傳與功能導引。 畫面包含自動輪播的視覺區塊與六大功能按鈕， 使用者可透過點擊快速進入拼圖、貼紙、濾鏡等編輯功能。

Collage Feature

拼圖功能提供多種版型（2~4張圖片）， 使用者可上傳多張圖片並選擇模板進行排列。 系統具備錯誤提示機制（圖片數量不足提醒）， 並提供隨機模板功能，增加使用趣味性。

Image Editing

圖片編輯功能整合五大工具：貼紙、濾鏡、調色、塗鴉筆與模板。 使用者可自由切換不同編輯模式， 並透過即時預覽確認效果。 操作介面設計簡潔， 並提供返回與確認機制， 確保編輯流程清楚且可控。

Completion + Gallery

完成頁在使用者編輯結束後提供成果展示， 並搭配彩帶動畫強化完成的儀式感。 使用者可選擇下載圖片或上傳至「展示牆」， 建立個人作品收藏空間。 展示牆支援圖片檢視、放大、刪除與批次管理， 讓整體體驗從創作延伸至保存與回顧， 形成完整的使用流程。

My Contribution

在「修起來」專案中，我主要負責介面設計與互動功能開發， 從版面規劃到動態效果皆有深度參與：

首頁 UI 設計與版面規劃
拼圖功能（上傳與模板）開發
完成頁動畫與視覺設計
展示牆功能設計與實作
整體介面美術與使用體驗優化

本專案最大的挑戰在於整合多種圖片編輯功能， 並維持操作的流暢性與直覺性。 在拼圖與展示牆功能中， 我多次調整互動流程與畫面呈現， 最終成功建立完整的「上傳 → 編輯 → 儲存 → 展示」使用體驗， 這也是本專案中最具成就感的部分。
