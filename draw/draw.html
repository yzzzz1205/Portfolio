小熊歷險記

Game Illustration / Opening Animation / Visual Storytelling

Project Type Unity Card Game
Tools Procreate / PowerPoint / Unity
Team / Role 5 People Team
Illustration / Animation

Project Overview

《小熊歷險記》是一款以敘事與插畫為核心的卡牌互動遊戲專案，透過童話風格的視覺與開場動畫，呈現小熊在失去家人後展開的成長旅程。 專案以四季森林為主軸，結合場景與關卡設計，營造隨時間推進的情境變化，並透過一致的視覺語言與簡易互動，引導玩家理解故事並建立情感連結。 整體以「回憶與成長」為核心概念，打造具有情緒層次的沉浸式童話體驗。

Opening Animation

Story Concept

小熊原本與家人過著平靜生活，卻在某天目睹父母被神秘 UFO 擄走。 為了找回家人，小熊踏上旅程，在四季森林與未知宇宙中， 憑著回憶與勇氣前進。

Design Concept

本專案以「回憶」作為情感核心，透過四季變化象徵時間與成長。 畫面風格採用柔和色彩與手繪筆觸，營造溫暖卻帶有一絲孤獨的童話氛圍。 每個關卡的視覺不僅是場景設計，也承載小熊與家人的記憶片段， 使玩家在遊戲過程中逐步建立情感連結。
