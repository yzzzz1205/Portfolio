咖啡點餐 App

Android Studio 製作的咖啡點餐應用程式

Project Type Mobile App
Tools Android Studio / Java
Team / Role 4 People Team
Dev / Data

Project Overview

這是一款以「快速點餐」為核心的咖啡訂購 App， 目標是解決使用者在忙碌情境下點餐流程繁瑣與選擇困難的問題。 透過簡化操作流程與推薦式介面設計， 讓使用者能在最短時間內完成點餐，提升整體體驗流暢度。

Design Concept

本 App 以「直覺與效率」為設計核心， 在介面上採用咖啡色與暖橘色作為主色調， 營造溫暖且具品牌感的點餐氛圍。 首頁採用推薦式設計，降低使用者選擇負擔， 同時提供快速下單與客製化兩種模式， 滿足不同使用情境下的需求。

Key Features

商品搜尋與分類瀏覽（咖啡 / 甜點）
分類切換與商品篩選機制
購物車即時更新與狀態同步
商品數量增減與刪除功能
結帳流程與付款方式選擇（模擬）
資料與 UI 動態同步更新機制

UI Design

以下為主要介面設計，包含首頁、菜單、購物車與付款流程。 整體設計強調清晰資訊層級與直覺操作。

My Contribution

在本咖啡點餐 App 專案中，我主要負責功能開發， 主要集中在菜單頁與購物車的互動邏輯實作，以及資料串接與操作流程控制：

菜單頁（咖啡 / 甜點）功能開發
頁面資料與版面結構調整
購物車功能開發
商品與購物車資料同步
購物車動態邏輯與狀態管理

在 Android Studio 開發過程中，版面配置相較於網頁更具挑戰性， 需要透過反覆調整 Constraint Layout 與元件層級來完成畫面排版。 同時購物車與商品資料之間的即時連動也是本專案的重點， 必須確保使用者在不同操作（加入、刪除、調整數量）時， UI 與資料能正確同步更新，此部分讓我更熟悉資料狀態管理與 UI 同步邏輯的實作流程。

Reflection

這是我第一次從使用者轉換為開發者的經驗， 讓我理解一個看似簡單的 App， 背後其實需要大量的邏輯設計與測試。 未來我希望能進一步優化功能， 例如加入訂單紀錄與推薦系統， 讓整體體驗更加完整。
